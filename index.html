Aplicaciones

MiEspol

App móvil para el campus de ESPOL. Calcula rutas peatonales con Dijkstra sobre un grafo del campus generado desde un mapa KML. Las rutas se ajustan al clima y a los obstáculos que reportan los usuarios. Incluye carnet digital, alertas e incentivos.

  • React Native
  • Expo
  • TypeScript
  • Leaflet

ESPOL Transport

Sistema de carpooling para estudiantes. Pasajeros y conductores se registran, publican horarios y se emparejan por zonas. Gestiona reservas con cupos, tarifas, cancelaciones y calificaciones. Incluye una API REST y una app Android nativa.

  • FastAPI
  • PostgreSQL
  • Alembic
  • JWT
  • Kotlin
  • Jetpack Compose
